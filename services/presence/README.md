## Поведение

Открытая видимая страница немедленно отправляет `/heartbeat`, затем повторяет его
каждые 10 секунд. Скрытая вкладка, свёрнутое приложение и уход со страницы
отправляют `/leave`. На переход/переподключение есть 3 секунды, чтобы посетитель
не исчезал при обычной навигации. Один браузер с несколькими вкладками считается
один раз. Другое устройство или очистка данных браузера — отдельный посетитель.

Если сигнал выхода потерян, присутствие истекает через 25 секунд после последнего
подтверждения. Значок запрашивает общее число каждые 3 секунды, поэтому обновление
экрана может отставать от изменения на сервере ещё на 3 секунды. Никто не должен
ждать минуту или нажимать поиск, чтобы учитываться: достаточно открыть приложение.

Все пользователи видят маленькое `● 12` над «Просмотрено» на главной. Это подпись,
не кнопка. Счётчик просмотров располагается ближе к погоде, с зазором 3 пикселя.
`/online` отдаёт только общее количество, без списка посетителей или их имён.
При недоступности сервиса отображается `—`, а не ноль.

Сервис не сохраняет адреса страниц, поиски или имена. Кратковременные анонимные
записи удаляются при следующих сигналах присутствия после истечения срока.
Публичный протокол не защищает от поддельных посетителей: число оценивает активные
браузеры, а не подтверждённые личности. CORS разрешает origin GitHub Pages.
Не добавлять секреты в `presence-config.js`. Серверная папка исключена из Pages.
