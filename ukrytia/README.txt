УКРЫТИЯ ИЗМАИЛА
=================

Папка: ukrytia

Файлы:
- index.html      — экран раздела
- style.css       — оформление
- app.js          — поиск, фильтры, кнопки карты/маршрута
- data.js         — список адресов и телефоны
- header-bg.jpg   — фон шапки

Подключение:
Откройте раздел по адресу /ukrytia/ или добавьте в главном меню ссылку на:
ukrytia/

Кнопка «Вернуться в главное меню»:
- если раздел открыт из главного приложения на том же домене, используется history.back();
- при прямом открытии переход идёт в ../

Важно:
Список адресов собран из перечня, который пользователь передал в переписке.
Перед публикацией рекомендуется сверить актуальность адресов и доступность конкретных укрытий с официальными сообщениями города/района.

«Найти рядом со мной» открывает поиск укрытий в Google Maps после запроса геолокации.
Точное расстояние в метрах в этой версии специально не выдумывается: для честного расчёта нужны подтверждённые координаты каждого объекта.
