# Погода Измаила: источники и поведение

Координаты запроса: 45.35, 28.84. Часовой пояс Europe/Kyiv.

Основной источник данных: DWD ICON Europe через [Open-Meteo](https://open-meteo.com/en/docs/dwd-api), модель `icon_eu`, пространственная сетка около 7 км, новый расчёт каждые 3 часа. Резерв: [ECMWF IFS](https://open-meteo.com/en/docs/ecmwf-api), `ecmwf_ifs`, через тот же API. Это резерв модели, а не независимого сервиса.

Приложение проверяет данные каждые 5 минут, при возвращении на экран и восстановлении соединения. Панель и эффекты получают один ответ. Текущие значения являются модельными расчётами, не наблюдением с датчика в каждом районе. 15-минутные значения вне регионов высокого разрешения могут быть интерполированы. Частый запрос не означает мгновенного обнаружения осадков.

Данные проверяются по времени (не старше двух часов, не из будущего более чем на 30 минут), температуре, ветру и погодному коду. После сбоя сохраняется последний корректный результат; устаревший результат обозначается в панели. Восход и закат из прогноза управляют освещением. Град и гроза отображаются только при соответствующем коде модели.

Сравнение: [OpenWeather](https://openweathermap.org/appid) требует API-ключ; [MET Norway](https://docs.api.met.no/doc/locationforecast/datamodel.html) использует глобальные данные порядка 9 км за пределами Скандинавии и [имеет ограничения прямых браузерных запросов](https://api.met.no/doc/locationforecast/HowTO). Оснований объявлять какой-либо сервис «самым точным» для каждого момента в Измаиле нет. Выбрана региональная модель, доступная без нового аккаунта и секретов.

Атрибуция: Weather data by [Open-Meteo.com](https://open-meteo.com/), DWD and ECMWF, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Преобразования: округление температуры, русские подписи и визуальные эффекты по WMO-кодам.
