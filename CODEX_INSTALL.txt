Готовая интеграция Frank Exchange.

Добавить все файлы из архива в репозиторий telegram-mini-app.

Затем:
1. Подключить main-v2/frank-rates.js на странице main-v2 после существующего кода курса.
2. Ничего в геометрии/дизайне остальных блоков не менять.
3. В main-v2/sw.js не кэшировать навечно main-v2/frank-rates.js и data/frank-rates.json: для них использовать network-first/no-store.
4. Старый NBU можно оставить как резерв: Frank Exchange должен перезаписывать отображаемые значения после загрузки JSON.
5. Клик по блоку курса должен открывать https://t.me/frankexange
6. Проверить GitHub Action вручную через workflow_dispatch.
7. После проверки commit + push в main.

Визуально блок:
FRANK EXCHANGE      куп / прод
USD                44.60 / 45.10
EUR                51.10 / 51.80
курс на 28.09.2026

GitHub Action обновляет данные каждые 10 минут, компьютер пользователя для этого не нужен.


Дополнение V2:
- Верхняя надпись FRANK EXCHANGE должна выглядеть как ссылка.
- Нажатие на FRANK EXCHANGE и на сам блок курса открывает https://t.me/frankexange
- Автообновление источника через GitHub Actions: каждые 10 минут.
- Проверка свежего JSON в открытом Mini App: каждые 5 минут.
