# Главный справочник Измаил

Версия сделана по исходному макету-картинке: вся картинка используется как единый дизайн, а поверх неё размещены прозрачные кликабельные зоны для каждой кнопки.

Структура:
- index.html
- styles.css
- app.js
- config.js
- assets/menu.png

Перед публикацией вставь реальные ссылки в `config.js`.
